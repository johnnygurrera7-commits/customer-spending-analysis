# Business Intelligence Analysis: Customer Spending Behavior

## 📊 Project Overview

This project analyzes customer spending behavior using transactional restaurant data. The objective is to uncover revenue patterns, customer behavior trends, and time-based spending insights through exploratory analysis and data visualization.

The project was developed using Python within a Jupyter Notebook environment and demonstrates foundational Business Intelligence and data analytics workflows.

---

## 🎯 Objectives

- Analyze spending behavior across different days of the week
- Compare customer spending patterns by gender
- Identify differences between lunch and dinner revenue trends
- Explore behavioral indicators such as smoking status
- Create visual dashboards for business insight generation

---

## 🛠 Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook
- Git & GitHub
