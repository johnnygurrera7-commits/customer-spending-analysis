# Business Intelligence Analysis: Customer Spending Behavior

## 📊 Overview
This project analyzes customer spending behavior using transactional data to identify patterns in revenue based on time, demographics, and behavioral factors.

## 🎯 Objectives
- Understand how spending varies across different days
- Analyze customer behavior by gender and habits
- Identify time-based revenue trends

## 🛠 Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📈 Key Insights
- **Weekend Revenue Trends:** Spending peaks on weekends, especially Sunday.
- **Customer Spending by Gender:** Male customers spend slightly more on average than female customers.
- **Time-Based Behavior:** Dinner generates higher average revenue than lunch.

## 📁 Project Structure
- `data/` → raw dataset  
- `notebooks/` → analysis notebook  
- `requirements.txt` → dependencies  

## 🚀 How to Run
1. Clone the repository  
2. Install dependencies:

pip install -r requirements.txt

3. Open the notebook:

notebooks/analysis.ipynb


## 📌 Conclusion
This analysis highlights how customer spending is influenced by time and behavior, providing insights that could support business decision-making.
